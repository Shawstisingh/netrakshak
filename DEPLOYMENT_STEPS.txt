1) Create a GitHub account or sign in.
2) Create a public repository named netrakshak-ai.
3) Upload all files in this folder (not the folder itself).
4) Visit https://share.streamlit.io/ and sign in with GitHub.
5) Create app -> choose netrakshak-ai -> branch main -> app.py -> Deploy.
6) Copy the URL Streamlit generates; that is your live project link.
